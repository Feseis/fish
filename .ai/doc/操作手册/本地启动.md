# 本地启动

状态：有效（产出物）
用途：从零启动认证服务与排障；跑不起来时读。
更新时间：2026-11-09

## 1 前置

- JDK 21、MySQL 8、Redis。
- 在仓库根目录执行命令，使用自带 wrapper。

## 2 建库

```powershell
mysql -u root -p < .ai\doc\建库\建库.sql
```

只建 `fish_auth` 库，表由 Flyway 在启动时创建。

## 3 环境变量

`a_run_env/auth.env` 不入库，首次拉代码后从模板复制并填真实值：

```powershell
Copy-Item a_run_env_example\auth.env a_run_env\auth.env
```

必须包含：

```text
AUTH_DB_URL=jdbc:mysql://localhost:3306/fish_auth?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
AUTH_DB_USERNAME=root
AUTH_DB_PASSWORD=******
REDIS_HOST=localhost
REDIS_PORT=6379
SMS_SERVICE_URL=http://localhost:8084
```

由 `spring.config.import: optional:file:./a_run_env/auth.env[.properties]` 读取，路径相对**仓库根**。`bootRun` 已在 `server8081-auth/build.gradle.kts` 固定 `workingDir = rootProject.projectDir`；IDE 直接运行时，运行配置的 Working directory 必须改成仓库根，否则 `optional:` 会静默跳过该文件，启动报 `AUTH_DB_URL` 占位符未解析。

## 4 启动

```powershell
.\gradlew :server8081-auth:bootRun
```

验证码发送依赖短信服务：先起 `.\gradlew :server8084-sms:bootRun`（8084）。短信服务再依赖 fish-pbox（默认 `http://localhost:8080`），pbox 未启动时发码返回 `SMS_SEND_FAILED`。

## 5 验收

```powershell
curl http://localhost:8081/auth/health
```

期望 `200` 且 body 为 `{"database":true,"redis":true}`。

## 5.1 跨服务事件手动投递

取消运单后 `event_outbox` 会新增一条待投递事件，当前需手动触发（定时任务见待办 `E-09`）：

```powershell
curl -X POST "http://localhost:8082/logistics/internal/outbox/dispatch?limit=50"
```

`delivered > 0` 表示已通知支付服务完成关单/退款；`retried` 表示支付服务不可用，稍后重复调用即可，投递幂等。

## 5.2 生成员工培训证明

先启动 auth（8081）与 logistics（8082），再执行：

```powershell
.\.ai\脚本\生成员工培训证明.ps1
```

依次输入手机号、岗位（1快递员 2客服 3司机）、归属网点序号，脚本调用 `POST /logistics/internal/staff-trainings` 并打印凭证码。

前提：手机号已在 App 注册，且 `auth_user_profile.real_name` 非空，否则返回 422 `REAL_NAME_REQUIRED`。同一账号同一岗位已有凭证时返回 409 `VOUCHER_EXISTS`。

脚本只调接口，不读写数据库；自定义地址用 `-BaseUrl http://192.168.1.10:8082`。

## 6 排障

- 启动报占位符未解析（`Driver ... claims to not accept jdbcUrl, ${AUTH_DB_URL}`）→ `auth.env` 未被读到；先看进程 cwd 是否为仓库根，再检查文件位置与键名。
- 404 而非 problem+json → `GlobalExceptionHandler` 未生效或异常发生在 Filter。
- 日志出现 `No MyBatis mapper was found` → `mapper` 包为空，属预期，不影响启动。
- `/auth/health` 返回 503 → 看 body 里哪项为 `false`，分别检查 MySQL 与 Redis。
- 根构建同时配置 Android 模块 → 属预期，`app` 模块需要 Android SDK。

## 7 安卓签名构建

需要 `keystore/fish-release.jks` 与仓库根 `key.properties`（密码见该文件，两者均不入库）。缺失时 release 自动退回 debug 签名。

```powershell
.\gradlew.bat :app:assembleRelease
& "D:\Program\Android\build-tools\36.1.0\apksigner.bat" verify --print-certs app\build\outputs\apk\release\app-release.apk
```

验收：`apksigner` 打印的 `SHA-1 digest` 与 `keytool -list -v -keystore keystore\fish-release.jks -alias fish` 一致。

手机已装 debug 包时，直接安装 release 包会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，需先卸载再去装。

## 8 高德地图

- Key 不入库：仓库根 `key.properties` 增加 `amapKey=<Android Key>`，构建时经 `manifestPlaceholders` 写入 Manifest；缺失时能打包，但地图不可用。
- 高德控制台 Key 的 PackageName 必须是 `me.feseis.fish`，并登记本机 debug 与 release 两枚 SHA1；换构建机要补新机器的 debug SHA1。
- 依赖只引 `com.amap.api:3dmap`，该包已内置定位 SDK（`AMapLocationClient`）；再引 `com.amap.api:location` 会重复类导致构建失败。
- 地图空白排查顺序：包名 → SHA1 → Key 是否注入 → `FishApp` 隐私合规调用是否早于地图创建。
- 地图瓦片由 App 内 SDK 直连高德，不消耗后端 Web 服务 API（regeo / POI）的每日配额。
