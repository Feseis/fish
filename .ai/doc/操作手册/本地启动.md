# 本地启动

状态：有效（产出物）
用途：从零启动认证服务与排障；跑不起来时读。
更新时间：2026-11-02

## 1 前置

- JDK 21、MySQL 8、Redis。
- 在仓库根目录执行命令，使用自带 wrapper。

## 2 建库

```powershell
mysql -u root -p < .ai\doc\建库\建库.sql
```

只建 `fish_auth` 库，表由 Flyway 在启动时创建。

## 3 环境变量

`a_run_env/auth.env` 不入库，首次拉代码后从模板复制并填真实值：

```powershell
Copy-Item a_run_env_example\auth.env a_run_env\auth.env
```

必须包含：

```text
AUTH_DB_URL=jdbc:mysql://localhost:3306/fish_auth?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
AUTH_DB_USERNAME=root
AUTH_DB_PASSWORD=******
REDIS_HOST=localhost
REDIS_PORT=6379
```

由 `spring.config.import: optional:file:./a_run_env/auth.env[.properties]` 读取，路径相对**仓库根**。`bootRun` 已在 `auth-server8081/build.gradle.kts` 固定 `workingDir = rootProject.projectDir`；IDE 直接运行时，运行配置的 Working directory 必须改成仓库根，否则 `optional:` 会静默跳过该文件，启动报 `AUTH_DB_URL` 占位符未解析。

## 4 启动

```powershell
.\gradlew :auth-server8081:bootRun
```

## 5 验收

```powershell
curl http://localhost:8081/auth/health
```

期望 `200` 且 body 为 `{"database":true,"redis":true}`。

## 6 排障

- 启动报占位符未解析（`Driver ... claims to not accept jdbcUrl, ${AUTH_DB_URL}`）→ `auth.env` 未被读到；先看进程 cwd 是否为仓库根，再检查文件位置与键名。
- 404 而非 problem+json → `GlobalExceptionHandler` 未生效或异常发生在 Filter。
- 日志出现 `No MyBatis mapper was found` → `mapper` 包为空，属预期，不影响启动。
- `/auth/health` 返回 503 → 看 body 里哪项为 `false`，分别检查 MySQL 与 Redis。
- 根构建同时配置 Android 模块 → 属预期，`app` 模块需要 Android SDK。
