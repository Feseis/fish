# 项目规范

状态：有效（产出物）
用途：稳定约束。写代码前读；变更约束时写。
更新时间：2026-11-02

## 1 项目定位与模块

- fish：快递系统毕业设计（飞鱼速递）。
- `app`：Android 客户端，applicationId `com.feseis.fish`。
- `auth-server8081`：独立认证服务，只负责账号、登录、会话与角色，不承载寄件/物流业务。
- `common`：目录保留，已从 `settings.gradle.kts` 移除，当前不参与构建。

## 2 技术栈

- Java 21；Spring Boot 4.1.2；Gradle 8.14.3（仓库自带 wrapper）。
- 持久层 MyBatis（`mybatis-spring-boot-starter` 4.1.0），表结构由 Flyway 管理。
- MySQL 库 `fish_auth`；Redis 存放短期令牌。
- Boot 4 已模块化：Flyway 自动配置在独立的 `spring-boot-flyway` 依赖中，不再随 `spring-boot-autoconfigure` 提供。
- 密码哈希只使用 `spring-security-crypto` 的 `BCryptPasswordEncoder`，不引入整套 Spring Security。

## 3 认证模型

- 手机号是唯一登录标识，`auth_account.phone` 唯一。
- 角色多对多：`auth_account_role`，永久授予，无有效期字段。
- 密码 1:1 存 `auth_password`；BCrypt 不可逆；`pwd_version` 改密时递增，用于让旧会话失效。
- 一次登录一行 `auth_session`；refresh token 原值只发给客户端，库中只存 SHA-256；状态 1 活跃 / 2 登出 / 3 被踢 / 4 过期。
- 双令牌分工：短期令牌放 Redis、可续签；refresh 只用于换新短期令牌（接口尚未实现）。

## 4 接口风格

- 成功：直接返回 DTO，HTTP 200，不包壳。
- 失败：RFC 9457 `ProblemDetail`，`Content-Type: application/problem+json`；HTTP 状态由 `ErrorCode` 决定，自定义属性挂 `code`、`timestamp`。
- `code` 取 `ErrorCode.name()`，与 `auth_login_log.fail_reason` 同一词表，改一处必须同步另一处。
- 禁止重新引入 `Result` 或 code-msg-data 统一壳（D-001）。
- 异常类型与全局处理只放在 `me.feseis.fish.auth.exp`；`@ExceptionHandler` 覆盖不到 Filter、容器层与异步线程的异常，需单独处理。

## 5 路径与包结构

- 服务前缀 `/auth`；健康检查子域 `/auth/health/**`。
- 类级 `@RequestMapping` 写完整前缀段，方法级只写相对段，禁止重复前缀。
- 包职责：`controller` 只做参数接收与响应；`exp` 放 `ErrorCode`、`AuthException`、`GlobalExceptionHandler`；`mapper`、`service`、`dto` 待建。

## 6 配置与环境

- 端口 8081；`spring.application.name=auth-server`。
- 环境变量来自 `a_run_env/auth.env`，由 `spring.config.import: optional:file:./a_run_env/auth.env[.properties]` 加载；`file:` 相对路径按**当前工作目录**解析，因此 cwd 必须是仓库根：`bootRun` 已在 `auth-server8081/build.gradle.kts` 固定 `workingDir = rootProject.projectDir`，IDE 运行配置的 Working directory 也必须设为仓库根。
- 必需键：`AUTH_DB_URL`、`AUTH_DB_USERNAME`、`AUTH_DB_PASSWORD`、`REDIS_HOST`、`REDIS_PORT`。
- Flyway `baseline-on-migrate=true`，脚本位于 `auth-server8081/src/main/resources/db/migration`。

## 7 数据库与迁移

- 建库脚本 `.ai/doc/建库/建库.sql` 只建库；表结构全部由 Flyway 管理。
- 字符集 `utf8mb4`；参与关联的字符列必须显式写 `COLLATE utf8mb4_general_ci`，否则 MySQL 8 取默认的 `utf8mb4_0900_ai_ci`，跨表 join 报 1267。
- 迁移失败：修脚本后 `flyway repair` 再 `migrate`，禁止手改 `flyway_schema_history`。

## 8 Redis 键设计（登录未实现，规划中）

- 所有键带 `auth:` 前缀，格式 `auth:{用途}:{标识}`。
- 一律设置 TTL，禁止永不过期的键。
- 短期令牌键规划为 `auth:st:{token}`，值含会话标识与 `account_id`，TTL 与短期令牌一致。
- 令牌原值不得进入键名或日志；必须落键时用 SHA-256 派生。
