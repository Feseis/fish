# 计费规则草稿

状态：草稿（不长期维护）
用途：运费与保价费的规则表讨论稿，含寄收关系字典、运费规则、保价规则与计费流程；定稿后分流至决策日志与待办。
更新时间：2026-11-09

## 已裁决口径

### 分区

- 只做三档寄收关系：`1同城 2省内 3跨省`，不建静态区域表。
- 「同城/省内」是寄出地与寄达地的相对关系，不是区县的固有属性；静态 `adcode → 价格区` 映射表达不了，强行做只能变成「寄出省 × 寄达省」矩阵，毕业设计无收益。
- 未来要加偏远地区差异时，另补 `remote_area` 与附加费规则，不改现有三张表。

### 重量

- **不做体积重**。所有快递件按小物件处理，`waybill.item_weight` 就是下单时用户填写的计费重量。
- 不引入长宽高、`chargeable_weight`。体积重整块的业务流程（揽收复核、多退少补）成本远高于收益。
- 计费重量按续重单位向上进位：不足一个 `extra_unit` 按一个计。

### 规则

- 规则只增不改：改价时停用旧行、插入新行，运单存当时的规则 ID，永远能还原费率。
- 同一 `freight_relation_id` 只允许一条 `enabled=1`，由应用层保证，数据库无法用普通唯一索引表达。
- 保价规则全局只有一条 `enabled=1`，全国统一费率，不分区。
- 金额统一 `ROUND_HALF_UP` 保留 2 位。

### 计费归属

- 计费接口放物流服务：`POST /logistics/price/quote`，下单时调用，返回三项金额与两个规则 ID。
- 运单只存金额快照与规则 ID，不存计算过程；规则 ID 是来源指针，不是过程。

### 默认值

- 保价费率 `0.0050`（0.5%），最低 1 元，最高申报价值不限。
- 示例运费：同城 首重 1kg / 8 元、续重 0.5kg / 2 元；省内 10 / 3；跨省 12 / 5。

## 寄收关系判定

`adcode` 前 2 位为省、前 4 位为市：

| 关系 | 判定 |
| --- | --- |
| 1 同城 | 前 4 位相同 |
| 1 同城（直辖市） | 前 2 位相同且属于 11/12/31/50 |
| 2 省内 | 前 2 位相同，前 4 位不同 |
| 3 跨省 | 前 2 位不同 |

省直辖县（如济源 419001）按省内处理。判定在代码中完成，不落表。

## freight_relation

```sql
CREATE TABLE freight_relation (
  freight_relation_id TINYINT UNSIGNED NOT NULL COMMENT '关系码，固定枚举，非自增',
  relation_name       VARCHAR(32)      NOT NULL COMMENT '关系名，如「同城」「省内」「跨省」',
  PRIMARY KEY (freight_relation_id),
  UNIQUE KEY uk_relation_name (relation_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci
  ROW_FORMAT=DYNAMIC COMMENT='寄收关系字典表';
```

| 码 | 关系 |
| --- | --- |
| 1 | 同城 |
| 2 | 省内 |
| 3 | 跨省 |

## price_rule

```sql
CREATE TABLE price_rule (
  price_rule_id       BIGINT UNSIGNED  NOT NULL AUTO_INCREMENT COMMENT '规则主键，自增；改价新建一条，不 UPDATE 历史行',
  freight_relation_id TINYINT UNSIGNED NOT NULL COMMENT '→ freight_relation.freight_relation_id',
  first_weight        DECIMAL(10,3)    NOT NULL COMMENT '首重重量 kg，如 1.000',
  first_price         DECIMAL(10,2)    NOT NULL COMMENT '首重价格 元',
  extra_unit          DECIMAL(10,3)    NOT NULL COMMENT '续重单位 kg，如 0.500',
  extra_price         DECIMAL(10,2)    NOT NULL COMMENT '每续重单位价格 元',
  enabled             TINYINT          NOT NULL DEFAULT 1 COMMENT '1启用 0停用；同一关系只允许一条启用',
  created_at          DATETIME         NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at          DATETIME         NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (price_rule_id),
  KEY idx_relation_enabled (freight_relation_id, enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci
  ROW_FORMAT=DYNAMIC COMMENT='运费规则表';
```

## insurance_rule

```sql
CREATE TABLE insurance_rule (
  insurance_rule_id  BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '规则主键，自增；改价新建一条',
  rate               DECIMAL(6,4)    NOT NULL COMMENT '保价费率，如 0.0050 表示 0.5%',
  min_fee            DECIMAL(10,2)   NOT NULL COMMENT '最低保价费 元',
  max_declared_value DECIMAL(10,2)   NULL     COMMENT '最高申报价值 元；NULL 表示不限',
  enabled            TINYINT         NOT NULL DEFAULT 1 COMMENT '1启用 0停用；全局只允许一条启用',
  created_at         DATETIME         NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at         DATETIME         NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (insurance_rule_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci
  ROW_FORMAT=DYNAMIC COMMENT='保价规则表';
```

## 计费流程

```
① 校验 sender_adcode、receiver_adcode 非空
② 按前 2/4 位判定 freight_relation_id
③ 取该关系下 enabled=1 的 price_rule；没有则拒绝下单
④ 若 weight <= first_weight：freight = first_price
   否则：units = ceil((weight - first_weight) / extra_unit)
         freight = first_price + units * extra_price
⑤ declared_value > 0 时：
   insured = max(declared_value * rate, min_fee)，insurance_rule_id = 当前启用规则
   否则 insured = 0，insurance_rule_id = NULL
⑥ total = freight + insured，三项均 ROUND_HALF_UP 到分
⑦ 运单写入 freight_amount、insured_fee、total_amount、price_rule_id、insurance_rule_id
```

## 算例

同城规则：首重 1kg / 8 元，续重 0.5kg / 2 元。

| 重量 | 计算 | 运费 |
| --- | --- | --- |
| 0.8kg | 未超首重 | 8.00 |
| 1.0kg | 等于首重 | 8.00 |
| 1.2kg | 超 0.2kg，进位 1 个 0.5kg | 10.00 |
| 2.3kg | 超 1.3kg，进位 3 个 0.5kg | 14.00 |

保价 1000 元、费率 0.5%、最低 1 元：`max(5, 1) = 5.00`。总额 19.00。

## 接口

`POST /logistics/price/quote`

```
入参：sender_adcode、receiver_adcode、item_weight、declared_value（可空）
出参：freight_relation_id、price_rule_id、insurance_rule_id、
      freight_amount、insured_fee、total_amount
```

接口只做试算，不落库；下单时再调用一次并以落库结果为准。两次调用之间规则可能改价，以下单时的结果为准。
